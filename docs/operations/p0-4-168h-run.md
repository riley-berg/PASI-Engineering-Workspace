# P0.4 — Engineering Workspace 168-hour run

The P0.4 acceptance run is anchored to the canonical backend issues in th3-st0v3/PASI-Engineering-Workspace. The supervisor reads the issue task checkboxes at runtime, persists evidence under the local PASI acceptance state directory, requires a clean committed worktree after each task, and pushes the run branch.

## Required local prerequisites

The checkout must be PASI-Engineering-Workspace. The real executor/controller must be available locally and exposed through PASI_ENGINEERING_EXECUTOR_CMD. A GitHub token must be supplied through PASI_GITHUB_TOKEN or GITHUB_TOKEN. The token is used only for canonical issue reads and to mark a completed task checkbox. Do not paste the token into source files or chat.

## Smoke

Run the fail-closed smoke before the 168-hour window:

    export PASI_GITHUB_TOKEN='...'
    export PASI_ENGINEERING_EXECUTOR_CMD='...'
    export PASI_PUSH=1

    python scripts/pasi_168h_acceptance.py --hours 168 --smoke

The smoke validates the Engineering Workspace repository, discovers the P0-P22 issues, and reports the number of checked/unchecked tasks without executing one.

## Full run

    ./scripts/run_p0_4_168h.sh

Runtime state:

    ~/.pasi/engineering-workspace-168h/state.json
    ~/.pasi/engineering-workspace-168h/events.jsonl
    ~/.pasi/engineering-workspace-168h/current-task.json

The supervisor is fixed to 168 hours. It stops early only when the canonical roadmap has no unchecked tasks remaining or when a task/executor fails. A failed task is recorded rather than silently skipped.

## Important boundary

This repository contains the roadmap/control-plane code. It does not silently fall back to personal-ai-system for the live executor. A real 168-hour run fails closed unless PASI_ENGINEERING_EXECUTOR_CMD points at an explicitly supplied local executor/controller.
